# Platform Engineering Lab

## Project Overview

This project simulates a real-world Platform Engineering team migrating a company's applications from Virtual Machines to Kubernetes.

The goal is to learn Platform Engineering by solving business problems instead of learning Kubernetes concepts in isolation.

---

# Business Scenario

Company: ShopSphere (Fictional)

Business:
An e-commerce company serving customers across India.

Current Challenges:
- Applications run on Virtual Machines.
- Manual deployments.
- Downtime during releases.
- Difficult to scale during sales.
- Limited monitoring and observability.

The CTO has decided to modernize the platform using Kubernetes.

---

# Business Requirements

- 500,000 monthly users
- Average 500 requests/second
- Peak 3,000 requests/second
- 99.9% availability
- Budget: $3,000/month
- Initial deployment in India
- Future expansion to Southeast Asia
